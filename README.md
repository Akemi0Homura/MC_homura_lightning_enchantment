i攻击后降下的闪电是特效，不用担心击杀生物后，掉落物被摧毁，也不会引发火灾或者伤害到自己。

特点：该附魔在生存模式只能附魔到剑上，但如果是创造模式附魔到弓、弩、三叉戟、雪球、方块等等，附魔都会生效。
